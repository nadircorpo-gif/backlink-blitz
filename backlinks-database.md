## Règles d'or

1. **Remplis à 100%** chaque profil (bio, photo, description, liens sociaux) — Google n'indexe pas les profils vides
2. **Étale sur 2-3 semaines** — pas 50 profils le même jour (ça flag comme spam)
3. **Contenu réel** sur les plateformes de publication (WordPress.com, Substack, Medium) — article 300+ mots minimum
4. **Les NoFollow comptent** — LinkedIn, YouTube, Reddit envoient des signaux de marque/entité
5. **Les marketplaces > les profils** — Gumroad, Dodo Payments, AppSumo = backlink + distribution réelle
6. **La pépite ultime** — Créer un petit plugin WordPress ou une extension Chrome liée à ton produit. DA 95+ DoFollow + distribution organique via le store
